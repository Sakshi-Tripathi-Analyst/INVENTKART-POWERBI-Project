# 📊 InventKart Sales Dashboard (Power BI)

## 📌 Project Overview
This project presents an interactive sales dashboard built using Power BI to analyze business performance for InventKart. It provides insights into sales trends, customer behavior, and key performance indicators.

## 🚀 Key Features
- Interactive dashboard with filters and slicers
- Sales analysis by region, category, and time
- KPI tracking (Revenue, Profit, Orders)
- Trend analysis and performance comparison

## 📊 Dashboard Insights
- Identified top-performing products and regions
- Analyzed monthly and yearly sales trends
- Highlighted profit-driving segments

## 🛠 Tools & Technologies
- Power BI
- DAX (Data Analysis Expressions)
- Data Cleaning & Modeling
